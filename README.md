# 📈 Stock Pilot

O **Stock Pilot** é um projeto acadêmico desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de aplicar na prática os conhecimentos adquiridos ao longo do curso.

O projeto foi criado com foco em tecnologia, organização e experiência do usuário, proporcionando a oportunidade de desenvolver habilidades em programação, desenvolvimento web e construção de interfaces.

## 🎯 Objetivo

Desenvolver uma aplicação web como parte de um projeto universitário, colocando em prática conceitos de desenvolvimento de software e ampliando conhecimentos técnicos por meio de um projeto real.
